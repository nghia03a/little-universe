# A Little Universe For You
Website tĩnh (HTML/CSS/JS thuần) chạy được trên GitHub Pages.
- Sửa lời nhắn: `js/story.js`
- Thay nhạc: đặt file `background.mp3` vào `assets/audio/`
- Thay ảnh: ghi đè các file trong `assets/images/` (giữ nguyên tên) hoặc đổi tên trong `js/story.js` và `index.html`
- Chạy thử: `python -m http.server 8000` rồi mở http://localhost:8000
